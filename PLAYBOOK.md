# Playbook: Regroup Happy Hour Deck

## Navigasi Keyboard Presentasi
- `Space` / `ArrowRight`: Slide berikutnya (atau reveal langkah berikutnya dalam slide aktif).
- `ArrowLeft`: Slide sebelumnya.
- `T`: Mulai / Pause Countdown Timer aktif.
- `R`: Reset Countdown Timer ke durasi default.
- `F`: Toggle Fullscreen browser.
- `M`: Mute / Unmute audio background.
